## 概述

本存储库（`@your-org/data-repository`）为项目提供统一的数据存储与访问能力，采用 **4路自适应数据源** 架构，按优先级自动降级获取数据。

### 设计目标

- **高可用性**：多级数据源自动降级，保障核心库稳定运行
- **高性能**：优先使用缓存，减少IO开销
- **可测试性**：内置Mock数据源，支持单元测试与联调
- **可观测性**：每级数据源访问埋点，便于问题定位

### 架构图
┌─────────────────────────────────────────────────────────┐
│ 核心库（调用方） │
└─────────────────────┬───────────────────────────────────┘
│
▼
┌─────────────────────────────────────────────────────────┐
│ Repository（自适应路由层） │
│ ┌─────────────────────────────────────────────────┐ │
│ │ Cache → DB → RPC → Mock （优先级降序） │ │
│ └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘


## 数据源优先级说明

| 优先级 | 数据源 | 说明 | 典型场景 |
|--------|--------|------|----------|
| 1 | Cache | 本地/远端缓存，TTL可配置 | 热点数据、高频读取 |
| 2 | DB | 业务数据库 | 持久化存储、一致性要求高 |
| 3 | RPC | 调用其他服务接口 | 跨服务数据获取 |
| 4 | Mock | 本地模拟数据 | 开发调试、单元测试 |

**路由逻辑**：按优先级顺序尝试获取数据，命中即返回；上级失败/超时自动降级到下级。
