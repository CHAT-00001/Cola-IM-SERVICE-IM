# live-chat-server 代码审查问题修复计划

## 1. 目标与范围

本计划针对 2026/10/27 对 `D:/rust/live-chat-server` 的静态审查结果，修复已确认的授权、WebTransport 生命周期与下行投递、敏感信息泄露和历史分页语义问题。

当前工作树在本计划开始前已有未提交改动，包括 `server/src/wt.rs`、`server/src/e2ee.rs`、`server/src/codec.rs` 以及相关装配代码。本次只在这些改动基础上做必要修复，不回滚或覆盖用户已有修改。

## 2. 已确认问题

| 优先级 | 问题 | 证据 | 影响 |
|---|---|---|---|
| P0 | 会话历史无法确认成员时仍继续查询 | `server/src/shared_handler.rs` 的 `conversation_history` | 已登录用户可能读取不属于自己的单聊/群聊历史 |
| P1 | WT Hub 下行队列只被排空，没有写入客户端 | `server/src/wt.rs` 的 `drain_hub` | WT 实时下行消息丢失 |
| P1 | WT 连接退出没有统一注销 Hub | `server/src/wt.rs` 的 `serve_connection` | 过期连接/设备映射、资源泄漏和错误投递 |
| P1 | WT 使用 `PassthroughE2ee`，但 README 宣称 E2EE | `server/src/app.rs`、`server/src/e2ee.rs` | 透传不提供端到端加密，存在能力误导和不安全上线风险 |
| P1 | 用户资料服务错误包含完整 URL、响应正文，URL 可能含 token | `server/src/service/identity/http.rs` | 凭据或上游敏感内容可能进入日志 |
| P2 | 历史接口文档使用客户端 `send_at`，存储却按服务端 `created_at` 翻页 | `server/src/message_handlers.rs`、`server/src/service/mongodb.rs` | 客户端时钟偏差时可能漏消息或重复消息 |

## 3. 修复方案

### 3.1 会话历史授权

1. 增加单聊会话成员查询入口和群聊成员查询入口。
2. 历史查询必须确认当前账号属于有效单聊或群聊成员。
3. 无法确认成员身份时返回 `ChatError::Unauthorized`，禁止按 ID 直接读取。
4. 为未授权路径补充服务层测试。

### 3.2 WT 下行与生命周期

1. 保留有界 Hub 队列。
2. 使用 `WebTransportSession::open_uni()` 为每条下行消息创建单向流，按现有长度前缀协议编码、E2EE seal 后写出。
3. 使用独立下行任务消费 Hub 队列；上行会话结束后取消下行任务。
4. 在所有会话结束路径调用 `hub.unregister`。
5. 队列满继续沿用现有显式断开策略。

### 3.3 E2EE 安全门控

1. 保留 transport-independent `E2eeHook` 接口和透传占位实现。
2. 新增 `server.wt.allow_insecure_passthrough`，默认 `false`。
3. WT 启用且只有透传实现时，默认启动失败；只有显式开发开关才允许透传并输出警告。
4. 本次不伪造真正的端到端加密实现。

### 3.4 敏感信息脱敏

1. 资料服务请求错误不再包含完整 URL或响应正文。
2. JSON 解析错误只返回固定的响应格式错误。
3. 非 2xx 只记录状态码和账号 ID，不记录 body/token。
4. 增加敏感内容不出现在错误文本中的测试。

### 3.5 历史分页语义

1. 将 `before` 文档改为服务端 `server_sync_at` 语义。
2. 保持 MongoDB 按服务端 `created_at` 查询，并明确两者由服务端写入时采用同一时间基准。
3. 复合游标（时间戳 + message_id）作为后续协议升级项，不在本次扩大范围。

4. 增加 WT 透传安全配置门控。

8. 检查计划文件、修改文件和 Git 状态。

## 5. 验收标准

- 非单聊成员或非群成员请求历史返回未授权，不返回消息。
- 有效单聊成员和群成员仍可读取历史。
- WT 客户端能通过单向流收到 Hub 下行消息。
- WT 会话结束后账号设备从 Hub 在线映射移除。
- WT 默认不允许透传 E2EE 静默启动；显式开发开关行为清晰可见。
- 身份服务错误不包含 access token、完整请求 URL或响应正文。
- 历史 `before` 参数与服务端时间语义一致。
- 格式检查、编译检查和可运行单元测试通过。

## 6. 非目标与遗留项

- 本次不引入跨节点 Hub/票据共享。
- 本次不实现复合历史游标协议。
